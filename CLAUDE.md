# OAL repository guidance

Read and follow [AGENTS.md](AGENTS.md), beginning with VERSION. The current English normative source is [Stable-v1.0.0](versioning/Stable-v1.0.0/README.md); Portuguese is its translation. The complete informative skill is in [versioning/Stable-v1.0.0/skill/](versioning/Stable-v1.0.0/skill/SKILL.md).

Preserve Alpha files and historical evidence byte for byte outside the explicit [operational allowlist](ALPHA-OPERATIONAL-ALLOWLIST.json). Use `python versioning/Stable-v1.0.0/run_examples.py NAME` from the root or `python run_examples.py NAME` inside that edition; each launcher is self-contained. No root launcher is required. Guides and agent files do not add OAL obligations. Use the verification and complete-skill installation instructions in AGENTS.md.
