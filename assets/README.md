# OAL images

[Português](README.pt-br.md) · [Home](../README.md)

The nine PNG files in this directory contain the OAL mark, two logos, bilingual banners, layer diagrams, and case-cardinality maps. The [English README](../README.md) uses the English images; the [Portuguese README](../README.pt-br.md) uses their Portuguese counterparts. The layer diagram and cardinality map appear at the same display width. Author photos load from GitHub's avatar service.

The six bilingual illustrations describe **Stable-v1.0.0**. They show four layers: UCS (L1), ADMV (L2), ADI (L3), and ADIB (L4). ADPM and ADVS are the two required components of the single ADMV layer. The layer diagram names the three adjacent derivation engines; the cardinality map shows case-identity relationships, not separate engines for the two L2 components. The dashed reference in the banner is an optional consultation of versioned UCS during derivation.

The PNGs retain the original canvas sizes and transparent areas. The OAL mark and logos are unchanged. See [editable sources](sources/README.md) for SVGs, the shared [bilingual labels](sources/labels.json), rendering instructions, and artwork provenance. The illustrations are informative; conformity is defined by the numbered requirements in the edition.
